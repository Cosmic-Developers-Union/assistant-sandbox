## 发布与外部下载复验

- 公开 Release：<https://github.com/Cosmic-Developers-Union/assistant-sandbox/releases/tag/v0.1.1>
- Test 工作流：<https://github.com/Cosmic-Developers-Union/assistant-sandbox/actions/runs/46049521363>
- Release 工作流：<https://github.com/Cosmic-Developers-Union/assistant-sandbox/actions/runs/46050020363>

在全新空目录执行：

```sh
gh release download v0.1.1 -D "$EMPTY_DIR"
cd "$EMPTY_DIR"
sha256sum -c SHA256SUMS
chmod +x assistant-sandbox-linux-amd64
./assistant-sandbox-linux-amd64 --version
```

摘要校验输出：

```text
assistant-sandbox-darwin-amd64: OK
assistant-sandbox-darwin-arm64: OK
assistant-sandbox-linux-amd64: OK
assistant-sandbox-linux-arm64: OK
assistant-sandbox-windows-amd64.exe: OK
```

`file` 核对五个资产分别为 Mach-O x86_64、Mach-O arm64、ELF x86-64、
ELF aarch64 与 PE32+ x86_64。版本输出为 `assistant-sandbox v0.1.1`。
上述默认与严格 PTY 记录均来自下载目录中的 linux/amd64 资产，而不是
工作树构建；默认记录 `bench: 21.289s`，结果和变量读回正确，严格记录
输出 `v22.23.5 riscv64 42`。
